OrderSignatures

Git Source

Title: OrderSignatures

Author: @msakiart

EIP-712 types for signed AsyncSwap actions. Every type spells out the maker, both tokens and the amounts so wallets render a readable message instead of opaque calldata.

  • AsyncOrder is the Permit2 witness for Router.swapWithSig (Permit2 domain).
  • SetExecutor and UpdatePrice are verified by the hook (AsyncSwap domain).
  • CancelOrder is verified by the Router (AsyncSwap Router domain).

PERMIT2_WITNESS_TYPE

Witness type string appended by Permit2 to PermitWitnessTransferFrom(...). Referenced types are sorted alphabetically per EIP-712.

        )
    );
