TokenClaims

Git Source

Redeems the caller's PoolManager currency claims to a chosen recipient.

Approve this contract for the currency claim ID on PoolManager before redeeming. Claim ownership and allowances are enforced by PoolManager.burn. No hook escrow is accessible.
