AsyncSwap

Git Source

Inherits: BaseHook, EIP712

Title: AsyncSwap

Author: @msakiart

Uniswap v4 hook that converts an exact-input swap into an open async order: the maker deposits their input via _beforeSwap. Crossing orders settle directly at the resting limit; fillers settle unmatched orders.

Makers can also act by EIP-712 signature (setExecutorWithSig, updatePriceWithSig) so a relayer pays gas and the wallet shows a readable message. See OrderSignatures for types.

Chain-specific USDC address. Every pool must include this exact currency.

router

The only swap caller the hook accepts, fixed at deployment. Only the Router settles a new order's input and hands it to matchNewOrder, so an order opened through any other caller would leave the transient pending-match id set for the rest of the transaction, and matchBook would skip that pool.

address public immutable router;

minOrder

Minimum order in numeraire base units (0: none), fixed at deployment for every pool so the owner cannot change the rules under live orders.

uint256 public immutable minOrder;

priorityFeeCap

$0.10 in numeraire base units, 10^(decimals - 1): the most a priority-bid floor can require.

uint64 public immutable priorityFeeCap;

assetPrecision

Decimal places of a whole asset token an order may trade, fixed at deployment: with 4, every order trades at least 0.0001 token on its asset side. 36 or more leaves only a 1-unit floor.

uint8 public immutable assetPrecision;

PENDING_NATIVE_DEPOSIT_SLOT

Transient slot — keccak256("asyncswap.hook.pendingNativeDeposit") - 1. Tracks ETH deposited to this contract within the current tx via receive(), so executeOrder can settle native output only out of the filler's just-received deposit rather than the contract's accumulated balance (which may include donations, stranded ETH, or in-flight native-input escrow). Cleared after each settle.

CannotRevokeTrustedRouter

Revoking the Router would strand the maker's live orders: Router.cancelOrder, cancelWithSig, fillOrder and fillFromPoolLiquidity all need the grant, and an EOA can't cancel from its own unlock. So the trusted Router can never be revoked; any other executor can.

 
error CannotRevokeTrustedRouter();
