# Contract reference

These pages are generated by `forge doc` from the NatSpec comments in
[`src/`](https://github.com/asyncswap/contracts/tree/main/src) on every docs build, so they always
match the code on `main`. Each page links to its source file.

| Contract | Role |
| --- | --- |
| [AsyncSwap](/reference/src/AsyncSwap) | The Uniswap v4 hook: turns swaps into orders, escrows input and bids, entry point for matching, fills and cancels. |
| [Router](/reference/src/Router) | Entry point for makers, fillers and relayers: `swap`, `fillOrder`, `cancelOrder`, `cancelAndWithdraw`, `withdrawClaims`, signed variants, `matchBook`, `fillFromPoolLiquidity`, and `multicall` to batch them. |
| [AsyncMatching](/reference/src/libraries/AsyncMatching) | Linked library that matches the book, fills from pool liquidity and settles each pair. |
| [AsyncFiller](/reference/src/libraries/AsyncFiller) | Order storage and the per-pool book: placement, fills, cancels, repricing, bid settlement. |
| [FeeVault](/reference/src/FeeVault) | Holds protocol fee and bid claims; the owner collects them. |
| [TokenClaims](/reference/src/TokenClaims) | Redeems ERC-20 PoolManager claims, such as match proceeds, to any recipient. |
| [NativeClaims](/reference/src/NativeClaims) | Redeems native ETH claims to any recipient. |
| [RadixPriceTree](/reference/src/libraries/RadixPriceTree) and [EligiblePrice](/reference/src/libraries/EligiblePrice) | The price index and the exact-price summaries that find the best crossing order. |

`MatchingEngine` is a standalone benchmark harness and is not deployed.
