Inherits: IAsyncSwapCallback

Title: RouterFlashFills

Author: @msakiart

The Router's flash-fill surface (IAsyncSwapCallback). The Router creates this module in its constructor and runs it by DELEGATECALL from its fallback, so every call executes as the Router: the hook sees the Router as caller, and the transient filler slot lives in the Router's context. Kept out of the Router so its runtime stays under EIP-170.

Called directly (not through the Router) every hook call reverts NotTrustedRouter.

_checkFill

Checks the live order against the filler's bounds and returns the output owed: the live minimum, at most maxPrice, for a live input of at least order.amountIn. A missing order is left for the hook to reject. The flash path charges no pool fee, so the hook burns exactly the live minimum it returns.
