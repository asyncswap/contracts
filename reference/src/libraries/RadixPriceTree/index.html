RadixPriceTree

Git Source

Patricia radix index for uint128 price levels. Inserts and removals traverse at most 128 branch bits; each distinct price creates one leaf and at most one branch node. Node ids released by remove are recycled by later inserts, so the id counter only grows with the peak number of simultaneously stored prices and can never be exhausted in practice (2^31 simultaneous levels).

_newNode

Reuse a released id first; only grow the counter when none is free. A freed id is referenced by nothing (its parent, sibling and leaves entries were rewired in remove), so reusing it cannot alias a live node.
